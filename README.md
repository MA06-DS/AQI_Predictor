# Pearls AQI Predictor

An end-to-end machine learning project to forecast the Air Quality Index (AQI) for the next three days using weather and pollution data.

## Tech Stack

- Python
- Scikit-learn
- TensorFlow
- Streamlit
- Flask
- OpenWeather API
- GitHub Actions
- SHAP
